# Neon Highway

Mobile-friendly endless car racing game built with HTML, CSS, and JavaScript. Features touch and swipe controls, responsive gameplay, obstacle avoidance, score tracking, coin collection, nitro boost, multiple cars, difficulty levels, day/night themes, and local high-score storage.

## Play

Open `index.html` in a browser, or serve the folder with any static web server.

## Controls

- Desktop: Arrow keys or WASD
- Mobile: Touch buttons or swipe left/right to change lanes; swipe up for a short nitro boost
- Nitro: Arrow Up, W, Shift, or Nitro button
- Pause: P or Escape

No backend or installation is required.
